# Praxen Analytics

Panel web estático de análisis y comparación de entrenamientos neuromusculares.

- Acceso con usuario y contraseña.
- Gestión administrativa y auditoría para superadministradores.
- API: https://api-praxen.onrender.com

## Despliegue en Vercel

Importa este repositorio, selecciona el framework **Other**, deja el comando de compilación vacío y utiliza la raíz del proyecto (`.`) como directorio de salida.

Agrega la URL definitiva del frontend a `CORS_ORIGINS` en Render para habilitar su comunicación con la API.
